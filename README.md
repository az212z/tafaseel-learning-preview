# منصة تفاصيل التعليمية — نسخة العرض 2.0

[افتح العرض](https://az212z.github.io/tafaseel-learning-preview/)

تجربة عربية RTL للإدارة والمدرب والطالب وولي الأمر قبل التشغيل النهائي. بيانات مصطنعة وحفظ في هذا المتصفح فقط. لا تدخل بيانات طلاب حقيقية أو هويات أو كلمات مرور.

دورات ودروس وواجبات واختبارات وحضور وتقارير وشهادات، وحقائب تعليمية وكتالوج تسجيل ومحاكاة دفع محلية وطلبات تسجيل طلاب وسجل تنبيهات غياب توضيحي. محاكاة الدفع لا تخصم أموالًا. زوم وSMS والسحابة تتطلب النسخة الأساسية وحسابات الخدمات؛ ليست خدمات مفعلة في GitHub Pages.

[المصدر وطلب المراجعة](https://github.com/az212z/tafaseel-training-center/pull/1). هذا المستودع يحتوي الناتج الثابت فقط؛ لا توجد قاعدة بيانات أو PHP أو أسرار. حذف بيانات الموقع يمحو إضافات التجربة. حدود العرض 10 MB لكل ملف و30 MB للمجموع.

## تجربة الخادم الكاملة مؤقتًا

[افتح إعداد GitHub Codespaces](https://codespaces.new/az212z/tafaseel-training-center/tree/feat/learning-platform?devcontainer_path=.devcontainer%2Flearning-platform%2Fdevcontainer.json). يتطلب تسجيل GitHub وإنشاء/استئناف بيئة خاصة، مع مراجعة حصة الاستخدام. الإعداد يشغّل PHP وقاعدة فعلية وحسابات بكلمات مرور عشوائية خاصة؛ لا ينشر على Hostinger. زر تشغيل التجربة الكاملة موجود في صفحة الدخول وشريط هذا الموقع. رابط الإعداد لا يعني أن بيئة المستخدم قد أُنشئت بالفعل.
