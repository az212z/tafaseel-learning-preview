# منصة تفاصيل — نسخة العرض

[افتح المنصة للتجربة](https://az212z.github.io/tafaseel-learning-preview/)

اختر الإدارة أو المدرب أو الطالب أو ولي الأمر، دون كلمات مرور.

هذه نسخة عامة ببيانات وهمية قبل النشر النهائي على استضافة المركز. التعديلات والملفات محفوظة داخل متصفحك فقط؛ لا توجد قاعدة بيانات مشتركة أو مصادقة حقيقية على GitHub Pages. لا تدخل بيانات أو جوالات أو ملفات طلاب حقيقية. إدخال الهوية ورفعها معطّلان. زر إعادة بيانات العرض يحذف إضافات التجربة من متصفحك فقط ويستعيد البيانات الأصلية.

يمكن تجربة الدورات والدروس والفيديو والملفات والواجبات والتقييم ومحاكاة الاختبارات والحضور والشهادات والتقارير والإعلانات والدعم.

هذا المستودع يحتوي ملفات العرض المبنية فقط. المصدر وتعليمات التشغيل الفعلي في [طلب المراجعة](https://github.com/az212z/tafaseel-training-center/pull/1). يحتوي build-manifest.json بصمات ملفات البناء. لم تُنشر ملفات PHP أو مفاتيح أو قواعد بيانات.
